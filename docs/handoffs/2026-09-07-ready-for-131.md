## The prize, and the risk that comes with it

The **t₀ marker is the part with teeth.** `validation/method.csv` records
`t0,0.525,min` as *driver-read from `run1-chromatogram.png` (solvent front)*, and
`t0_marker,solvent front` says outright: *"no marker compound injected … a uracil
confirmation would make it audit-grade (campaign #27)."* So this was already contemplated
one campaign ago and never done.

**If the measured t₀ comes back different from 0.525 min, it re-baselines the project's
validated numbers.** Every figure in SPEC §10 — the three-layer bar, the v0.2 gradient
freedom bar, the held-out Rs ratios — is stated at t₀ = 0.525, and there is precedent for
exactly this churn: [#24](https://github.com/zhipengzhu1-dotcom/24-Aug-2026-HPLC-Simulator-v0.1.0/issues/24)
re-baselined every fixture from 0.6 to 0.525 and needed its own follow-up
(`task/24-rebaseline`, PR #67, and `docs/handoffs/2026-09-03-ticket-24-complete.md`).

Plan for that outcome before measuring, rather than discovering it afterwards. A marker
that confirms 0.525 is cheap; one that moves it is a second ticket. Say so on #131 up front
so the driver is choosing with eyes open.

The method for the injection is `validation/PROTOCOL.md` §1: uracil or thiourea, column
installed, any isocratic condition, at the flow in use — t₀ is its retention time. Record
which marker was used.

## Gotchas that have bitten before

- **`validation/method.csv` is CRLF.** Preserve the line endings when editing, or the diff
  becomes the whole file.
- **Dwell volume is fixed at 0.375 mL** — the instrument's own value, driver's decision
  2026-09-02. Never substitute a data-tuned dwell. It is stored as a volume; the engine
  derives `t_D = V_D / F` at entry.
- The `sample` row is the **last line** of `method.csv` and both datasets share that one
  file for method constants, but `validation/Validation_2/` is a *different mixture* — its
  `README.md` says so without saying what it is. Two identities are needed, and there is
  currently only one place to put them. Decide where the second goes.
