1 Measure the dwell volume

Do this first — it is quick and everything else is biased if it is wrong. Current value in method.csv is 0.375 mL taken off a spec sheet, never measured. A wrong dwell shifts every prediction in the same direction.

Method (PROTOCOL.md §1): replace the column with a zero-dead-volume union. A = water, B = water + ~0.1% acetone. Detector ≈ 265 nm. Program a sharp linear 0 → 100 %B at 0.400 mL/min. Read tD at the midpoint of the absorbance rise.

If the measured VD differs from 0.375 mL by more than about 10%, say so before running anything else — every held-out number in SPEC §10 was computed with the old value and would need re-deriving.

2 Spike in a near-critical pair

The sample is three peaks at Rs 30–116. Nothing is close to co-eluting, which is why SPEC §10's Rs ± 0.3 bar is still unmet and the resolution map is parked. All three runs below still predict a critical pair at Rs 32–34 — so without a spike, tomorrow adds no resolution evidence at all.

Add something that elutes near an existing unknown. A rough co-elution is worth more here than another clean separation. Record what you added and roughly how much.
